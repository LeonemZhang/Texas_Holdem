# 当前局号显示时机执行计划

> 生命周期：normal

## 目标

将桌面进度区和结算区的“第 X 局”改为消费服务端权威快照中的当前局号；已结算局在结算及全员准备窗口稳定显示第 N 局，只有下一局创建后显示第 N+1 局。`room.completedHands` 继续表示已完成局数并在结算进入牌局准备时增加，不移动该业务递增时机。

## 范围

- 包含：`packages/protocol` 快照 schema、Host 当前局号权威投影、客户端桌面进度与结算显示、协议/Host/客户端 targeted tests，以及相关产品规格、牌局生命周期设计和协议与同步设计同步。
- 不包含：移动 `completedHands` 的递增时机、盲注增长、发牌、牌局状态机、SQLite 持久化或迁移、Android Host、客户端重连及其他并行任务。

## 依赖

- 外部：无。
- 任务依赖：`HANDNUM-001` 无任务内依赖；实现顺序必须是协议边界确认、Host 投影与测试、客户端显示与测试、文档同步，但由同一任务一次完整交付。
