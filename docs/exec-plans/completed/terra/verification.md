# Terra 验收证据

这是 Terra 工程骨架计划的归档证据入口。历史计划内容保留在同目录的 `plan.md`；后续代码验证以仓库实际提交和 `docs/verification/` 中的验收记录为准。

## 归档范围

- pnpm workspace、应用和共享包骨架。
- TypeScript、ESLint、Prettier、Vitest 和构建脚本。
- Electron sandbox、context isolation 和窄 preload 边界。
- 房主服务健康检查和基础实时接入。
- 根 `AGENTS.md`、当前 `INVARIANTS.md`、`ARCHITECTURE.md` 和产品规格入口。

## 历史状态

本文件不伪造某次运行的测试计数；需要具体命令、提交或 Windows smoke 证据时，查阅对应的 `docs/verification/` 归档记录。
