# 客户端断线自动恢复执行计划

> 生命周期：normal

## 目标

玩家或房主客户端发生非主动网络断开后，在不改变 Host 权威性、房间身份、命令幂等和持久化语义的前提下，以固定 `500 ms` 间隔自动重连最多 `20` 次，达到上限后转入手动模式，手动重连使用相同的间隔和尝试次数，且仅在收到当前房间和玩家匹配的权威快照后恢复操作。

## 范围

- 包含：客户端连接事件、显式自动重连调度、Socket.IO adapter 生命周期、房间快照就绪门控、恢复与失败状态 UI、相关客户端测试、产品规格与客户端设计同步。
- 不包含：修改 Host 权威服务、Socket.IO 服务端默认重连参数、扑克规则、命令幂等协议、SQLite 持久化、LAN discovery、Android Host 计划或其他并行任务。

## 依赖

- 外部前提：Host 当前在新认证 Socket 连接后发送 `state:snapshot`，且保存房间、玩家、筹码和历史；本计划不要求新增服务端协议。
- 任务依赖：`RECON-002` 依赖 `RECON-001`；`RECON-003` 依赖前两个任务并可在通过后同步文档。
