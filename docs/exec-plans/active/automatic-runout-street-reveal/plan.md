# 自动 Runout 逐街展示执行计划

> 生命周期：normal

## 目标

在自动 Runout 条件下，由服务端权威地按 `2s` 间隔逐街公开翻牌、转牌和河牌，并在河牌公开后等待 `2s` 再摊牌结算；客户端只显示服务端发布的每个中间快照，不本地推断或延迟牌面。

## 范围

- 包含：`poker-core` 一次推进一街、Host 自动 Runout 计时与快照持久化、暂停/关闭/恢复清理、相关产品/设计/不变量文档与测试。
- 不包含：协议字段或协议版本变更、前端规则与本地延迟推断、Android/MCP、客户端重连及其他并行计划。

## 依赖

- 外部前提：现有服务端已具备下注轮关闭判定、可行动玩家判定、逐玩家快照发布和持久化机制。
- 任务依赖：`RUNO-002` 依赖 `RUNO-001`；`RUNO-003` 依赖 `RUNO-001` 和 `RUNO-002`。
