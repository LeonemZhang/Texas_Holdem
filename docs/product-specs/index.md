## 产品定位

Texas Hold'em 是供朋友通过实体或虚拟局域网对战的无限注德州扑克游戏。房主 Windows 客户端同时运行房间服务，其他玩家通过 Windows 客户端或浏览器连接。项目不依赖公网大厅、账号、支付、语音、跨设备房主迁移、分布式防作弊、排位商城或复杂动画。

## 产品验收原则

- 玩家不能通过客户端伪造筹码、牌面或行动结果。
- 浏览器和 Windows 客户端对同一房间呈现一致状态。
- 每个牌局状态都能解释当前行动者和合法行动集合。
- 除明确筹码转移外，筹码不能凭空增加或消失。
- 非房主掉线不会删除玩家或对局数据。
- 房主正常关闭和异常退出具有不同持久化状态。
- 房间等待、牌局准备和实际对局必须可区分。
