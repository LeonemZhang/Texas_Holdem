# Texas Holdem v1.0.2

v1.0.2 是面向朋友局的功能与问题修复发布，重点改善退出恢复、玩家展示和牌局提前结束时的稳定性。

## 功能变更

- 玩家从大厅退出后，可以使用原身份恢复，并在恢复到大厅时更换昵称。
- 玩家在牌局中退出后，仍可使用原身份恢复，不会创建新的座位。
- 被房主移除的玩家不再显示在牌桌中，并在统计排名中排在仍在房间中的玩家之后。
- 简化牌桌上的局数文案，让当前牌局进度更易读。

## 问题修复

- 修复翻牌或转牌阶段，玩家加注、过牌或跟注后对手弃牌可能出现“Command handling failed”的问题。
- 修复上述弃牌失败后房间停留在当前牌局、无法继续操作的问题。
- 修复牌局提前结束时使用不完整公共牌进行牌型统计导致结算失败的问题；翻牌前只有两张底牌时不会进入牌型统计。

## 下载

- `Texas Holdem-1.0.2-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.2-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网。
