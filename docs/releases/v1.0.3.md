# Texas Holdem v1.0.3

v1.0.3 是面向牌桌体验的功能优化发布，重点提升牌桌信息展示和操作音效反馈。

## 功能变更

- 牌桌状态行显示当前大小盲注，方便玩家随时确认当前盲注级别。
- 牌桌中央显示当前牌型（如"同花"、"两对"），结算时主动摊牌的玩家也展示牌型。
- 优化操作音效，并为行动阶段增加读秒提示音。

## 下载

- `Texas Holdem-1.0.3-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.3-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网。
