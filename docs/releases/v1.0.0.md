# Texas Holdem v1.0.0

这是 Texas Holdem 的首个公开版本，面向朋友通过实体局域网或 EasyTier 等虚拟局域网进行 2–10 人无限注德州扑克。

## 主要内容

- Windows 房主运行权威房间服务，Windows、手机和电脑浏览器可以共同加入。
- 支持完整行动、全押、主池与边池、平分和奇数筹码分配。
- 支持局域网扫描、IP 直连、邀请链接和二维码。
- 支持首局前房主拖拽换座、随机打乱和移出玩家。
- 支持指定玩家筹码请求、公开记录、统计与局内称号。
- 支持断线重连、异常对局恢复和房主本机 SQLite 历史记录。
- 服务端权威执行发牌、计时、行动与结算，并按玩家隔离隐藏底牌。

## 下载

- `Texas Holdem-1.0.0-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.0-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机说明

房主创建房间时选择其他玩家可访问的实体网卡或虚拟网卡。同网玩家可扫描房间或通过 IP 直连；浏览器玩家打开 `http://<房主IP>:32100`。

异地玩家可按照 README 使用 EasyTier 组成虚拟局域网。EasyTier 是独立第三方项目，本项目不集成或重新分发 EasyTier。默认推荐虚拟 IP 直连，不依赖 UDP 广播中继，也不建议将游戏端口直接映射到公网。

## 系统与显示要求

- Windows 10/11 x64。
- 桌面布局最低支持基准为原生 1920×1080、Windows 100% 显示缩放和普通最大化窗口。
- 手机浏览器最低支持 360 CSS 像素宽度。

本次发布候选已在 Windows 11 x64 `10.0.26200` 完成 ZIP 与 MSI 的安装、启动和卸载 smoke；Windows 10 x64 尚未在独立环境中复测。

## 数据与兼容性

- 对局数据保存在房主电脑的 `%APPDATA%\Texas Holdem\rooms`。
- 当前线协议版本为 v3，房主和玩家应使用同一版本客户端。
- 协议 v1、v2 以及缺少筹码历史时间戳的早期开发快照不兼容。
- 早期开发版保存在其他目录的数据不会自动迁移；升级或清理前请自行备份。

## 已知边界

- 不提供公网大厅、账号、支付、语音或跨设备房主迁移。
- HTTP/Socket.IO 应用层不自行提供 TLS 或端到端加密。
- 虚拟网络节点和中继线路质量会影响延迟。
- 本次发布候选尚未完成两个不同公网出口之间的 EasyTier 实机验收。
- 更低桌面分辨率、更高显示缩放或低高度还原窗口只作尽力兼容。
