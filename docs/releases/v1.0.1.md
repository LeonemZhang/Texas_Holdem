# Texas Holdem v1.0.1

v1.0.1 是面向朋友局的维护发布，统一源码与 Windows 产物版本，并重新核验当前响应式界面组件。

## 本次更新

- 统一根项目、全部 workspace、房主服务和桌面安装包的版本号为 `1.0.1`。
- `UiSmokePreview` 改用当前牌桌、结算、统计和座位相关组件所需的最新快照字段，包含行动顺序、最近行动、结算数据和牌型记录数据。
- 增加预览回归检查，确认统计面板可以打开当前“牌型记录”视图，而不是只渲染旧版外壳。
- 修复桌面端对 `@texas-holdem/protocol` 的直接依赖声明，确保干净 pnpm 安装与 GitHub Actions 的类型检查一致。
- README 界面预览重新从当前组件生成，覆盖牌局、结算、大厅、统计和筹码交换的桌面与手机尺寸。

## 下载

- `Texas Holdem-1.0.1-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.1-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网。默认使用虚拟 IP 直连，不要求 UDP 广播中继。
- 仍不提供公网大厅、账号、支付、语音或跨设备房主迁移。

## 验收边界

本版本的本机 Windows 11 x64 安装、启动、卸载、打包资源最小联机牌局、全量质量门禁和 GitHub Actions 由对应验收记录与检查链接确认。Windows 10 独立机器和跨公网 EasyTier 实机链路仍需要额外环境，不能由当前单机环境替代。
