# Texas Holdem v1.0.5

v1.0.5 是房主管理、观战、牌局恢复与自动推进体验的功能版本，重点改善服务型房主、动态房间配置、断线恢复、开局后加入和全押后的牌局反馈。

## 功能优化

- 创建房间时可选择“参与游戏”或“仅提供服务”两种房主模式。服务型房主不占用玩家座位或筹码，可通过 Windows 客户端进入只读观战牌桌，查看公共牌、底池、行动和已经公开的摊牌信息。
- 两种房主模式都可使用房主管理入口。首局开始后，房主可以修改房间名称、行动时长、下一局准备等待时长、当前小盲、盲注增长和筹码耗尽策略；当前牌局已生效的盲注、底池、筹码和截止时间不会被回算。
- 牌局开始后仍可加入新玩家。新玩家等待下一局，并须在准备阶段主动选择“就绪”后参赛，不会进入当前已经创建的牌局。
- 服务端提供权威当前局号：结算和准备阶段继续显示刚结束的第 N 局，下一局真正创建后才切换为第 N+1 局。
- 全押后没有可继续行动时，自动 Runout 按 `2s/2s/2s/2s` 节奏逐街公开公共牌；河牌公开后等待 2 秒再进入摊牌结算，并配套倒计时与翻牌反馈音效。
- 增加客户端断线自动恢复：以固定 `500 ms` 间隔最多尝试 `20` 次；自动恢复结束后可按原参数手动重连。权威快照完成匹配前，房间操作保持锁定且不会重复发送旧命令。
- 统一牌局准备阶段的操作文案为“就绪”，并继续优化移动端牌桌、房主管理和结算反馈布局。

## 问题修复

- 修复重连门控期间“开始游戏”命令被吞掉的问题。
- 修复服务型房主从本地记录恢复后无法进入观战牌桌的问题。
- 修复盲注增长配置在编辑多位数时过早校正，改为输入完成后再进行最小值保护。
- 调整全押后 Runout 音效音量，避免明显高于其他牌桌音效。
- 修复手机端房主管理面板中移出玩家按钮宽度异常的问题。

## 工程与质量

- 新增 MCP 玩家适配器，可通过独立 stdio Agent 完成连接、准备、行动、连续牌局和进程重启后的同身份恢复。
- 补充 Host/Player 身份边界、服务型房主观战、动态房间配置、自动 Runout、断线恢复和开局后加入的产品规格、设计文档、ADR、不变量与验证证据。
- 完善仓库 Harness 和 workspace 架构门禁；Windows 继续是唯一 Host 运行端，手机端和 Android 仅作为普通玩家入口。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网；多网卡扫描失败时仍可使用 IP 直连。
