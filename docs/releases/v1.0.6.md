# Texas Holdem v1.0.6

v1.0.6 聚焦准备阶段筹码处理，以及玩家退出或被移出后的牌桌与统计展示一致性。

## 功能优化

- 准备阶段增加筹码重置投票。当房间使用“请求其他玩家给予筹码”策略且有玩家筹码不足以参加下一局时，系统会自动发起投票；房主也可以在准备阶段手动发起。只有本次投票中的所有玩家同意，投票玩家的筹码才会恢复为初始值。
- 筹码重置成功后，相关玩家需要重新确认就绪；投票失败时筹码不变，筹码重置不计入牌局净输赢。

## 问题修复

- 修复主动退出或被房主移出的玩家仍出现在大厅、牌桌、结算、统计、筹码交换和房主管理列表的问题。
- 修复退出或移出玩家导致的桌面显示、统计展示和对局记录人数口径不一致问题。
- 主动退出玩家仍可使用原设备恢复；被房主移出的玩家在本房间内不能继续操作或恢复，但相关历史记录仍会保留。

## 下载

- `Texas Holdem-1.0.6-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.6-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网；多网卡扫描失败时仍可使用 IP 直连。
