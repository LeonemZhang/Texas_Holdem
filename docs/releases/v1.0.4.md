# Texas Holdem v1.0.4

v1.0.4 是面向牌桌稳定性与联机体验的问题修复发布，重点改善行动顺序、结算统计和房间配置体验。

## 功能变更

- 支持房主在大厅修改房间配置，并可在牌局内查看邀请信息。
- 增加结算输赢与持平音效，让牌局结果反馈更清晰。
- 改善多网卡局域网环境下的房间加入体验。
- 扫描到牌桌后点击“加入”即可弹出昵称输入框，确认后直接进入房间；大厅退出后重新扫描还可使用新昵称恢复原身份。

## 问题修复

- 修复换座后行动顺序、座位顺时针布局和行动位显示偶发错乱。
- 修复多人入池后的牌局称号、统计与“铁公鸡”展示错误。
- 修复弃牌获胜、主动摊牌和未摊牌获胜时牌型统计记录错误。
- 修复多个玩家在不同轮次全押时的主池、边池结算错误。
- 修复增长盲注后的当前盲注显示与行动校验不同步。

## 下载

- `Texas Holdem-1.0.4-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.4-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网。
