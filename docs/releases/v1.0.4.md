# Texas Holdem v1.0.4

v1.0.4 是面向朋友局的功能优化与稳定性修复版本，重点改善房间配置、盲注增长、多人牌桌布局、结算信息和局域网加入体验；同时收敛桌面与移动端的下注交互、底池统计和牌型统计展示，并补强仓库质量门禁。

## 功能优化

- 房主可以在首局开始前直接修改房间人数上限、初始筹码和盲注配置；修改后大厅座位、玩家筹码和准备状态保持一致。
- 房主管理面板支持在牌局中复制当前房间邀请链接和二维码，方便玩家重新进入。
- 扫描到可加入的房间后，点击“加入”会先打开昵称确认弹窗；大厅阶段退出的玩家重新扫描时会预填原昵称，并允许在原身份上修改昵称恢复。
- 增加盲注增长配置：不增长、倍率增长和步长增长。支持按局数设置增长间隔、小盲上限，表单会在输入过程中即时校正；大盲始终跟随当前小盲为两倍。
- 牌桌和牌局准备阶段显示当前实际生效的盲注，准备资格与下一局参赛校验也会使用当前盲注。
- 优化结算展示：本人结果置顶并显示为“我”，清晰显示“胜利”“失败”或“平局”；收起结算详情后仍保留公共牌、底池、本人底牌和当前牌型信息。
- 结算结果增加独立的胜利、失败和持平音效；下注筹码飞向底池时显示筹码面额，动画更易理解。
- 优化牌桌座位与窗口布局：支持多人局本人座位信息一致展示，移动端座位队列包含全部玩家并按行动顺序滚动，桌面端加注区与本人下注统计布局更清晰。
- 放大移动端公共牌和本人底牌，支持移动端牌桌按实际视口等比缩放；桌面端默认以 1920×1080 目标尺寸窗口化启动。
- 统一牌桌进度文案，将牌局轮次显示为“第 X 局”，并优化“加注到”和“追加”等操作文字。
- 优化桌面端跟注控件，使其与移动端保持一致的布局和金额展示；跟注金额为 0 或操作不可用时，仍保留统一的“跟注 0”呈现。
- 优化底池统计行：桌面端居中展示总池和分街道底池，窄桌面与移动端会按可用空间安全缩放并保持统计信息可读。

## 问题修复

- 修复全押牌局在当前下注轮尚未结束时提前推进街道的问题；只有下注轮完成后，确实没有两名仍有筹码的竞争者时才自动补牌到河牌。
- 修复多个玩家在不同街道依次全押时的主池、边池、未匹配贡献退回和最终筹码结算问题，并补充筹码守恒校验。
- 修复换座后行动顺序没有按照物理座位顺时针推进的问题；修复多人座位布局、庄家/盲注位置和行动顺位偶发显示错乱。
- 修复弃牌获胜、未摊牌获胜和主动摊牌时牌型统计记录错误；修复多人入池后的“倒霉蛋”、牌局称号和“铁公鸡”展示错误。
- 修复盲注增长后牌桌显示、牌局准备资格和下一局参赛校验仍使用旧盲注的问题。
- 修复多网卡主机扫描发现时使用不可达地址，以及使用多网卡直连加入后牌桌连接失败的问题。
- 修复桌面端已有房主进程占用端口时重复启动房主服务的问题，改为给出明确的占用提示。
- 修复窄桌面统计面板中最佳五张牌换行或挤压的问题，五张牌现在保持同排展示。

## 工程与质量

- 重组仓库文档入口，补充产品规格、设计文档、决策记录、执行计划和验证证据的索引与模板，降低后续维护和发布核对成本。
- 新增仓库 Harness 检查，并接入本地与 CI 质量门禁，覆盖文档结构、链接、任务标识和验证约束；该项不改变牌局规则、网络协议或用户操作流程。

## 下载

- `Texas Holdem-1.0.4-x64.msi`：推荐安装方式，后续版本可通过 MSI 就地升级。
- `Texas Holdem-1.0.4-x64.zip`：免安装便携版，不参与 MSI 升级。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256 校验值。

仅从本仓库 Release 页面下载。当前产物未进行代码签名，Windows 可能显示 SmartScreen 或未知发布者提示。

## 联机与兼容性

- 房主使用 Windows 客户端运行权威房间服务，其他玩家可从 Windows、电脑浏览器或手机浏览器加入。
- 同一牌局的房主和玩家应使用同一版本客户端；当前协议版本为 v3。
- 支持实体局域网和 EasyTier 等虚拟局域网；多网卡扫描失败时仍可使用 IP 直连。
